# Simulador Residencial: Gestão de Energia

Simulador educacional interativo para explorar potência elétrica, consumo de energia, estimativa de custos e hábitos de economia.

## Acessar o simulador

- **Versão web:** https://brenner279.github.io/simulador-residencial/
- **Versão offline para Chromebook:** https://brenner279.github.io/simulador-residencial/offline/

## Usar sem internet no Chromebook

Para usar a versão local sem depender de conexão:

1. Baixe este repositório em ZIP: https://github.com/Brenner279/simulador-residencial/archive/refs/heads/main.zip
2. Extraia o arquivo no aplicativo Arquivos do Chromebook.
3. Abra a pasta `offline` e execute `index.html` com o Chrome.

A versão da pasta `offline` reúne os estilos e scripts no próprio HTML e não depende de bibliotecas, fontes ou imagens externas. Consulte [offline/README.md](offline/README.md) para ver as instruções de instalação e uso.

## Conteúdos trabalhados

Matemática, potência elétrica, consumo em kWh, porcentagem, proporcionalidade, estimativa de custos, educação financeira e sustentabilidade.
